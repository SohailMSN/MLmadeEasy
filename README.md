🚀 MLmadeEasy
💡 Machine Learning for Everyone – Stylized, Simplified & Supercharged!
🎨 Pixel Art meets Finance + ML in a colorful, interactive Streamlit app.

🎯 What is MLmadeEasy?
MLmadeEasy is a multi-page Streamlit application that guides users through the entire machine learning workflow—from uploading financial datasets to training, evaluating, and exporting models. With a neon-pixel-art theme and intuitive UI/UX, it makes working with ML both fun and educational.

✨ Key Features

📁 Upload CSV or fetch stock data via Yahoo Finance

🧹 Simulate preprocessing (future-ready for automation)

🛠️ Interactive feature engineering

🔀 Train/Test split with animated pie chart

⚙️ Model training: Linear/Logistic Regression, Clustering

📊 Model evaluation with real-time metrics

🎯 Result predictions with fun effects

🎨 Neon/pixel-art UI with theme toggling

📤 Export models and results

📚 About section for course details and credits

🧠 Tech Stack

Streamlit

Plotly

yFinance

Scikit-learn

Joblib

CSS + pixel art for design

💻 Getting Started

Clone the repository
git clone https://github.com/SohailMSN/MLmadeEasy.git

Install dependencies
pip install -r requirements.txt

Run the app
streamlit run app.py
